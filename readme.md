## Setup

For my Keychron K12, bootloader can be accessed by jumping the left two pins underneath the spacebar, or when the custom keymap is flashed, FN2+B.
I have only been able to get the bootloader to flash via Sonix Keyboard Flasher. I included the binary since its deprecated: `./Sonix Keyboard Flasher.exe`.
